# Security

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's
[security advisory form](https://github.com/Castor-o7/muster/security/advisories/new),
not in a public issue. Include what you found, how to reproduce it, and what it affects.

## Scope

Muster is designed for one operator's own machines, on a private network or a VPN.
The [security model](README.md#security-model) describes what it protects and how.
Reports about the daemon's gate, pairing, session binding and message delivery are all in scope.
